# 사유의 빛 · 반가사유상 디지털 전시

3D 작품 감상, 부위별 음성 도슨트, 윤곽 진동 탐색을 결합한 HCI 과제입니다.

## 체험
https://huiyueun.github.io/sayu-light/

별도 설치 없이 위 주소를 Chrome에서 여세요. 진동 탐색은 Android Chrome에서 실제 기기로 확인했습니다. 브라우저와 기기 설정에 따라 진동 지원이 다릅니다. 음성 안내는 기기의 한국어 음성을 사용합니다.

## 사용 방법
- 01/02 작품 선택, 좌우 회전, 이동, 확대/축소, 시점 선택을 사용할 수 있습니다.
- 터치 버튼은 첫 터치에 선택 표시와 음성 안내, 다음 터치에 실행됩니다.
- 부위 이름이나 숫자를 선택하면 해당 부위로 확대하며 설명합니다.
- '손끝으로 느끼기'는 바라보던 방향을 유지하며 전신을 맞춘 뒤 윤곽을 표시합니다.
- 작품 안을 손가락으로 짚으면 진동하고, 밖으로 나가거나 손을 떼면 멈춥니다.
- '탐색 종료'도 첫 선택에 안내하고 다음 선택에 종료됩니다.

## ZIP에서 실행
압축을 모두 푼 뒤 Python 3이 설치된 컴퓨터에서 이 폴더로 이동하여 실행하세요.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

Windows에서는 `py -m http.server 8000 --bind 127.0.0.1`을 사용해도 됩니다.
브라우저에서 http://127.0.0.1:8000/ 에 접속하세요. index.html을 더블클릭하는 file:// 방식은 지원하지 않습니다.
3D 라이브러리와 모델은 포함되어 있습니다. Google Fonts는 온라인일 때 불러오며 오프라인에서는 시스템 글꼴로 표시됩니다.

## 구성 및 배포
- index.html / style.css: 화면 구성
- viewer.js: Three.js와 앱 로직을 포함한 실행 번들
- models.json: 두 작품의 경로와 출처
- *.glb / *.webp: 모바일 최적화 모델·색상·노멀맵
- THIRD_PARTY_LICENSES.txt: 라이브러리 라이선스
- SOURCES.txt: 유물 출처 및 가공 내역

GitHub Pages는 main 브랜치의 루트(/)를 게시하도록 설정합니다.
원본 대용량 스캔과 개발 중 캡처는 포함하지 않습니다. 도슨트는 과제용 해설이며 박물관 공식 음성 안내가 아닙니다.
